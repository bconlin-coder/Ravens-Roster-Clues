# Name that Raven

A standalone Baltimore Ravens roster trivia game.

## GitHub Pages

This repository is ready to publish from the repository root.

1. Upload `index.html` and `.nojekyll` to the root of the repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.

`index.html` is the site's entry page.
